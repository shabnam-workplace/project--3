# Weather App

## Description
This is a simple weather app that allows users to search for the weather conditions of any city worldwide. The app fetches real-time weather data from the OpenWeatherMap API and displays the current temperature, weather condition, humidity, and wind speed.

## Features
- Search for weather by city name
- Displays the following data:
  - Temperature (in Celsius)
  - Weather description (e.g., Clear, Rain, Cloudy)
  - Humidity percentage
  - Wind speed (in meters per second)
- Responsive design for both mobile and desktop
- Fetches data dynamically using JavaScript

## Technologies Used
- **HTML**: Structure of the app
- **CSS**: Styling, including responsiveness
- **JavaScript**: Fetches data from the OpenWeatherMap API and updates the UI dynamically

## API Used
- **OpenWeatherMap API**: [https://openweathermap.org/api](https://openweathermap.org/api)
  - You can get your own free API key after signing up.

# Interactive Quiz App

## Description
This is an interactive quiz app built using HTML, CSS, and JavaScript. The app allows users to answer multiple-choice questions, provides instant feedback, and calculates the score at the end. It supports a dynamic question set and is fully responsive, ensuring it works on mobile, tablet, and desktop devices.

## Features
- Multiple choice quiz with various questions
- Instant feedback on each question (correct/incorrect)
- Score calculation at the end of the quiz
- Mobile and desktop responsive design
- Simple, user-friendly interface

## Technologies Used
- **HTML**: Structure of the quiz app
- **CSS**: Styling and responsive design
- **JavaScript**: Logic for quiz functionality, question navigation, and score calculation

## How to Use
1. Open the `index.html` file in your browser to load the quiz app.
2. The quiz will display a series of questions with multiple-choice answers.
3. Select an answer for each question and click the "Submit" button to move to the next question.
4. At the end of the quiz, your score will be displayed along with an option to restart the quiz.

## Features Walkthrough
- **Question Navigation**: Users can progress through the quiz by clicking the "Submit" button after answering a question.
- **Feedback**: After each question, users will see whether they answered correctly or not.
- **Score Display**: After completing all questions, users will see their final score and can restart the quiz.
